# Events

> **Carried over, not yet regenerated.** Built from the schema files of the
> v1 branch (`master`, commit d55677d, 14 November 2026). In 2.3.0 these
> schemas move into the server under the `passport` namespace and this page
> is generated by `passport-plugin reference`. Until the move is done, treat
> the field lists as a guide: they were written by hand and have never been
> checked against live events. One known error throughout: fields shown as
> `string (uuid)` that hold a Passport record id are not UUIDs. They are
> `passport.id` (short text such as `Ch3oep6QbWZm8q5XEjgS5`), corrected in the
> server's embedded copies.

The body of each built-in event, read as `trigger.body` in an automation
started by it. `trigger.user_id` is the member the event is about, when
there is one. Declare the shape on the trigger:

```yaml
on:
  - event: user.created
    schema: { $ref: passport/schemas/user.created@^1 }
```
